# Helena Bronze

Site inicial estático. Abra `index.html` para visualizar.

## Publicar
1. Crie o repositório `helena-bronze` no GitHub.
2. Envie `index.html` e `README.md` para a raiz.
3. Importe o repositório na Vercel como projeto estático (sem framework).
4. Após receber logo, fotos, valores, endereço e cursos, substitua os textos provisórios.

O botão de agendamento abre o WhatsApp; ainda não há calendário de reservas.
